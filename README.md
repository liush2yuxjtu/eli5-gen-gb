# eli5-gen-gb

Grok Bot skill: **Explain Like I'm 5** with **AI-generated** comic panels (`GenerateImage`), interleaved with short chat text.

Not HTML attachments. For code-drawn SVG panels see sibling [`eli5-svg-gb`](https://github.com/liush2yuxjtu/eli5-svg-gb).

## Install

```bash
npx skills add liush2yuxjtu/eli5-gen-gb --skill eli5-gen-gb -g -y
```

Or on Grok Bot: paste / sync this `skills/eli5-gen-gb/SKILL.md` as a user skill.

## Trigger

`/eli5-gen-gb` or “explain this simply with generated pictures”.
